# TG Saver

## Запуск (VPS / любой сервер с Python 3.10+)
```
pip install -r requirements.txt
export BOT_TOKEN=токен_от_BotFather
export ADMIN_ID=твой_числовой_id   # узнать в @userinfobot; потом нажми /start у бота
python bot.py
```
Несколько аккаунтов: каждый подключает ОДНОГО И ТОГО ЖЕ бота в Telegram для бизнеса
(у каждого нужен Premium). Всё от всех прилетает в админ-чат с подписью «Аккаунт: …».
Список подключённых: команда /accounts.

Доставка: каждое событие уходит И в админ-чат, И в чат с ботом самого подключённого
аккаунта. Чтобы второе работало стабильно, с каждого аккаунта один раз нажми /start у бота
(сразу после подключения Telegram даёт боту писать туда только ограниченное время).
Исчезающие медиа от юзербота дополнительно падают в «Избранное» этого аккаунта.
Опционально: `RETENTION_DAYS=14` (сколько хранить архив), `DATA_DIR=data`.

## Аватарка бота
Файл `avatar.png` лежит в архиве. Поставить: @BotFather → `/setuserpic` → выбрать бота → отправить `avatar.png` как фото.

## Подключение
1. @BotFather → создать бота → в настройках бота включить **Business Mode**.
2. У тебя должен быть Telegram Premium.
3. Настройки → Telegram для бизнеса → Чат-боты → выбрать бота, дать право читать сообщения.
4. Бот пришлёт «Подключился» — готово.

Что делает: хранит входящие (текст + фото/видео/голосовые/кружки/файлы/стикеры),
при удалении собеседником присылает тебе копию, при редактировании — «было/стало».

Ограничения Business API: бот не получает одноразовые/исчезающие медиа и секретные чаты;
файлы больше 20 МБ не скачиваются; сообщения, пришедшие до подключения, не восстановить.

## Исчезающие фото (userbot_ttl.py)
```
export API_ID=... API_HASH=... BOT_TOKEN=... ADMIN_ID=...
export SESSIONS=acc1,acc2,acc3
python userbot_ttl.py login acc1   # один раз на аккаунт: телефон и код
python userbot_ttl.py login acc2
python userbot_ttl.py run          # все аккаунты разом
```
Исчезающие фото и видео со всех аккаунтов приходят в тот же админ-чат через бота.

## Хостинг
Бот должен работать 24/7 (VPS или Railway/Fly). Токен и API_HASH никому не показывай.
